A **Restrição de Acesso do PlayerHUD** é uma extensão complementar obrigatória do
[Bloco PlayerHUD](https://github.com/jeanlucio/moodle-block_playerhud). Ela permite ao professor
restringir o acesso a atividades, recursos ou seções do curso com base no progresso do estudante
no PlayerHUD.

Ela se conecta diretamente ao sistema nativo de **Restringir acesso** do Moodle, liberando
conteúdo apenas quando o estudante atinge um determinado **Nível**, possui um **Item**
necessário, pertence a uma **Classe de personagem**, ou tem a **gamificação ativa**.

Use a barra lateral para ir a qualquer seção desta página.
